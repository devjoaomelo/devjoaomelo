## Projetos em Destaque

### [AgroSolutions - Plataforma IoT para Agricultura 4.0](https://github.com/devjoaomelo/fiap-AgroSolutions)

> Sistema completo de agricultura de precisão com microserviços .NET 8, mensageria e dashboard interativo

**Arquitetura:**
- 4 Microserviços (.NET 8): Identity, Property, Ingestion, Alerts
- Event-Driven com RabbitMQ + MassTransit
- PostgreSQL (Database per Service)
- Frontend Blazor WebAssembly
- Observabilidade: Prometheus + Grafana
- CI/CD: GitHub Actions
- Kubernetes ready

**Tecnologias:**
`C#` `ASP.NET Core` `Entity Framework` `RabbitMQ` `PostgreSQL` `Docker` `Kubernetes` `Blazor` `Prometheus` `Grafana`
